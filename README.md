# ✈️ FlightDealAsia — 便宜機票 Deals

蒐集亞洲地區的便宜機票優惠資訊，僅顯示**最近 3 天**的 Deal，過期自動移除。

🌐 **線上預覽**：[https://saojsm.github.io/FlightDealAsia](https://saojsm.github.io/FlightDealAsia)

---

## 📋 欄位說明

| 欄位 | 說明 | 範例 |
|------|------|------|
| 日期 | Deal 發佈日期 | `2026-09-04` |
| 天數 | 旅遊天數 | `10` |
| 出發地 | 機場代碼 + 城市 | `TPE 台北` |
| 到達地 | 機場代碼 + 城市 | `NRT 東京` |
| 價格 | 票價（新台幣） | `4,500` |
| 航空公司 | 執飛航空公司 | `台灣虎航` |
| 購買平台 | 預訂平台或 OTA | `易遊網` |
| DEAL 截圖 | 懸停可預覽截圖，支援多張 | 🖼️ 預覽 (3) |

---

## 🔍 如何篩選

頁面頂部提供即時篩選功能，可自由組合：

- **出發地** — 下拉選單篩選特定出發城市
- **到達地** — 下拉選單篩選特定目的地
- **旅遊天數** — 下拉選單篩選特定行程天數
- **航空公司** — 下拉選單篩選特定航空公司
- **購買平台** — 下拉選單篩選特定預訂平台
- **價格排序** — 由低到高 或 由高到低排序
- **清除篩選** — 一鍵重置所有篩選條件

> 💡 **截圖預覽**：滑鼠移到「🖼️ 預覽」上可查看大圖預覽（支援多張滾動）；**直接點擊按鈕或圖片即可在新分頁開啟高清原圖**，手機用戶亦可輕鬆點擊看大圖！
